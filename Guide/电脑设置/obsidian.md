# 二、配置
## 2.1 插件
参考[b站视频](https://www.bilibili.com/video/av115553561739950)

| 序号 |  名称   |   功能  |  链接   |
| --- | --- | --- | --- |
|   1 |  git   |  用以自动同步   |  [github代码仓](https://github.com/Vinzent03/obsidian-git)   |
|   2 |  custom-attachment-location   |  用以自动整理md文件中的图片   |  [github代码仓](https://github.com/RainCat1998/obsidian-custom-attachment-location)   |
|   3 |  enhancing-export   |  用以将md导出为X格式   |  [github代码仓](https://github.com/mokeyish/obsidian-enhancing-export)<br>该插件依赖pandoc，自行前行[pandoc的github代码仓](https://github.com/jgm/pandoc)下载   |
|   4 |  File Explorer Note Count  |   左侧目录栏，计算md文件数量  |  Obsidian插件商店   |
|   5 |  Iconize  |   左侧目录栏，修改文件/目录的图标  |  Obsidian插件商店   |
|   6 |  Style Settings  |   对主题进行定制修改。可以修改Heading 2、3 的颜色等  |  Obsidian插件商店   |
